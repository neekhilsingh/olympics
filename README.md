# 🏅 Olympics Data Analysis Dashboard

An interactive data visualization project built using Tableau to explore historical Olympic Games data. This dashboard provides insights into medal distribution, country performance, athlete demographics, and participation trends over time.

---

## 📊 Project Overview

This project analyzes Olympic data to uncover meaningful patterns and trends across different countries, years, and athlete characteristics. The dashboard is designed to make data exploration intuitive and visually engaging.

---

## 🚀 Features

- 🌍 **City Map Visualization** – Displays host cities and participation distribution  
- 🥇 **Medal Tally Analysis** – Country-wise gold, silver, and bronze medals  
- 📈 **Year-wise Trends** – Participation growth over time  
- 🌎 **Country-wise Analysis** – Performance comparison across nations  
- 🧑‍🤝‍🧑 **Athlete Insights** – Age distribution, gender ratio, height & weight analysis  
- ⭐ **Top Athletes & Sports** – Identify top-performing athletes and popular sports  

---

## 🛠️ Tools & Technologies

- Tableau (Data Visualization)
- Excel / CSV (Dataset)
- Data Cleaning & Transformation
